Installare The Ultraspeaker Flipbook Lab

Ultimo aggiornamento: 12 novembre 2026

Titolare: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

La versione web non si installa: apri niki977.github.io/ultraspeaker-flipbook-lab in Chrome, Edge o Safari aggiornati, su computer, tablet o telefono.

1 · Sulla schermata Home

  • iPhone e iPad (Safari): tocca Condividi → Aggiungi alla schermata Home. Compare l'icona «Flipbook Lab».
  • Android (Chrome): menu ⋮ → Aggiungi a schermata Home (o Installa app).
  • Computer: in Chrome ed Edge puoi installarla dall'icona nella barra degli indirizzi, oppure salvarla tra i preferiti.

2 · Pannello di PowerPoint

Il pannello per PowerPoint è in fase di prova e sarà disponibile a breve. Nel frattempo usa la versione web.

Il pannello aggiunge il pulsante Flipbook Lab nella scheda Home, gruppo The Ultraspeaker, e apre l'app nel browser. Ti serve il manifest ultraspeaker-flipbook-lab-manifest.xml, che trovi nel repository github.com/niki977/ultraspeaker-flipbook-lab o che ti mandiamo su richiesta. Punta già a https://niki977.github.io/ultraspeaker-flipbook-lab/: non devi modificarlo.

Requisiti: PowerPoint di Microsoft 365 per Mac, per Windows o per il web.

PowerPoint per Mac

  1. Chiudi PowerPoint (⌘Q).
  2. Nel Finder premi ⌘ + Maiusc + G e incolla: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Se non c'è, crea una cartella chiamata wef e copia dentro il manifest. Se c'è già una versione precedente, sostituiscila.
  4. Apri PowerPoint e una presentazione: in Home trovi il gruppo The Ultraspeaker con il pulsante Flipbook Lab.

Se compare ancora la versione vecchia: chiudi PowerPoint, svuota ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches e riaprilo.

PowerPoint per Windows

  1. Crea una cartella, per esempio C:\FlipbookLab, e copia dentro il manifest.
  2. Tasto destro sulla cartella → Proprietà → Condivisione → Condividi…, scegli il tuo utente, Condividi e Fine. Annota il percorso di rete (simile a \\NOME-PC\FlipbookLab).
  3. In PowerPoint: File → Opzioni → Centro protezione → Impostazioni Centro protezione… → Cataloghi di componenti aggiuntivi attendibili. Incolla il percorso di rete in URL catalogo, Aggiungi catalogo, spunta Mostra nel menu, poi OK.
  4. Chiudi e riapri PowerPoint, vai su Home → Componenti aggiuntivi → CARTELLA CONDIVISA, seleziona The Ultraspeaker Flipbook Lab e Aggiungi.

PowerPoint per il web

Home → Componenti aggiuntivi → Altri componenti aggiuntivi → I miei componenti aggiuntivi → Carica il mio componente aggiuntivo e seleziona il manifest.

3 · Prova

  1. Fai clic su Home → Flipbook Lab: si apre il pannello.
  2. Fai clic su Apri Flipbook Lab: l'app si apre nel browser.
  3. Apri la guida di esempio, crea un video in MP4 con colore e inseriscilo con Inserisci → Video → Video da file.

Installing The Ultraspeaker Flipbook Lab

Last updated: 12 November 2026

Owner: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

The web version needs no installation: open niki977.github.io/ultraspeaker-flipbook-lab in an up-to-date Chrome, Edge or Safari, on a computer, tablet or phone.

1 · On the home screen

  • iPhone and iPad (Safari): tap Share → Add to Home Screen. The “Flipbook Lab” icon appears.
  • Android (Chrome): menu ⋮ → Add to Home screen (or Install app).
  • Computer: in Chrome and Edge you can install it from the icon in the address bar, or bookmark it.

2 · PowerPoint pane

The PowerPoint pane is being tested and will be available soon. In the meantime use the web version.

The pane adds the Flipbook Lab button to the Home tab, in the The Ultraspeaker group, and opens the app in your browser. You need the manifest ultraspeaker-flipbook-lab-manifest.xml, available in the repository github.com/niki977/ultraspeaker-flipbook-lab or from us on request. It already points to https://niki977.github.io/ultraspeaker-flipbook-lab/: you do not need to edit it.

Requirements: Microsoft 365 PowerPoint for Mac, Windows or the web.

PowerPoint for Mac

  1. Quit PowerPoint (⌘Q).
  2. In the Finder press ⌘ + Shift + G and paste: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. If it is not there, create a folder called wef and copy the manifest into it. If an earlier version is already there, replace it.
  4. Open PowerPoint and a presentation: in Home you will find the The Ultraspeaker group with the Flipbook Lab button.

If the old version still appears: quit PowerPoint, empty ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches and open it again.

PowerPoint for Windows

  1. Create a folder, for example C:\FlipbookLab, and copy the manifest into it.
  2. Right-click the folder → Properties → Sharing → Share…, choose your user, Share and Done. Note the network path (similar to \\PC-NAME\FlipbookLab).
  3. In PowerPoint: File → Options → Trust Center → Trust Center Settings… → Trusted Add-in Catalogs. Paste the network path in Catalog Url, Add catalog, tick Show in Menu, then OK.
  4. Close and reopen PowerPoint, go to Home → Add-ins → SHARED FOLDER, select The Ultraspeaker Flipbook Lab and Add.

PowerPoint for the web

Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in and select the manifest.

3 · Try it

  1. Click Home → Flipbook Lab: the pane opens.
  2. Click Open Flipbook Lab: the app opens in your browser.
  3. Open the sample guide, create a video as MP4 with colour and insert it with Insert → Video → Video from file.

Instalar The Ultraspeaker Flipbook Lab

Última actualización: 12 de noviembre de 2026

Titular: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

La versión web no se instala: abre niki977.github.io/ultraspeaker-flipbook-lab en Chrome, Edge o Safari actualizados, en ordenador, tableta o móvil.

1 · En la pantalla de inicio

  • iPhone y iPad (Safari): toca Compartir → Añadir a pantalla de inicio. Aparece el icono «Flipbook Lab».
  • Android (Chrome): menú ⋮ → Añadir a pantalla de inicio (o Instalar aplicación).
  • Ordenador: en Chrome y Edge puedes instalarla desde el icono de la barra de direcciones o guardarla en favoritos.

2 · Panel de PowerPoint

El panel para PowerPoint está en fase de prueba y estará disponible pronto. Mientras tanto, usa la versión web.

El panel añade el botón Flipbook Lab en la pestaña Inicio, grupo The Ultraspeaker, y abre la app en el navegador. Necesitas el manifiesto ultraspeaker-flipbook-lab-manifest.xml, que encontrarás en el repositorio github.com/niki977/ultraspeaker-flipbook-lab o que te enviamos si lo pides. Ya apunta a https://niki977.github.io/ultraspeaker-flipbook-lab/: no tienes que modificarlo.

Requisitos: PowerPoint de Microsoft 365 para Mac, Windows o la web.

PowerPoint para Mac

  1. Cierra PowerPoint (⌘Q).
  2. En el Finder pulsa ⌘ + Mayús + G y pega: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Si no existe, crea una carpeta llamada wef y copia dentro el manifiesto. Si ya hay una versión anterior, sustitúyela.
  4. Abre PowerPoint y una presentación: en Inicio encontrarás el grupo The Ultraspeaker con el botón Flipbook Lab.

Si sigue apareciendo la versión antigua: cierra PowerPoint, vacía ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches y vuelve a abrirlo.

PowerPoint para Windows

  1. Crea una carpeta, por ejemplo C:\FlipbookLab, y copia dentro el manifiesto.
  2. Clic derecho en la carpeta → Propiedades → Compartir → Compartir…, elige tu usuario, Compartir y Listo. Anota la ruta de red (parecida a \\NOMBRE-PC\FlipbookLab).
  3. En PowerPoint: Archivo → Opciones → Centro de confianza → Configuración del Centro de confianza… → Catálogos de complementos de confianza. Pega la ruta de red en URL del catálogo, Agregar catálogo, marca Mostrar en menú y luego Aceptar.
  4. Cierra y vuelve a abrir PowerPoint, ve a Inicio → Complementos → CARPETA COMPARTIDA, selecciona The Ultraspeaker Flipbook Lab y Agregar.

PowerPoint para la web

Inicio → Complementos → Más complementos → Mis complementos → Cargar mi complemento y selecciona el manifiesto.

3 · Prueba

  1. Haz clic en Inicio → Flipbook Lab: se abre el panel.
  2. Haz clic en Abrir Flipbook Lab: la app se abre en el navegador.
  3. Abre la guía de ejemplo, crea un vídeo en MP4 con color e insértalo con Insertar → Vídeo → Vídeo desde archivo.

Installer The Ultraspeaker Flipbook Lab

Dernière mise à jour: 12 novembre 2026

Titulaire: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

La version web ne s'installe pas : ouvrez niki977.github.io/ultraspeaker-flipbook-lab dans Chrome, Edge ou Safari à jour, sur ordinateur, tablette ou téléphone.

1 · Sur l'écran d'accueil

  • iPhone et iPad (Safari) : touchez Partager → Sur l'écran d'accueil. L'icône « Flipbook Lab » apparaît.
  • Android (Chrome) : menu ⋮ → Ajouter à l'écran d'accueil (ou Installer l'application).
  • Ordinateur : dans Chrome et Edge, vous pouvez l'installer depuis l'icône de la barre d'adresse, ou l'ajouter aux favoris.

2 · Volet PowerPoint

Le volet pour PowerPoint est en phase de test et sera bientôt disponible. En attendant, utilisez la version web.

Le volet ajoute le bouton Flipbook Lab dans l'onglet Accueil, groupe The Ultraspeaker, et ouvre l'app dans le navigateur. Il vous faut le manifeste ultraspeaker-flipbook-lab-manifest.xml, disponible dans le dépôt github.com/niki977/ultraspeaker-flipbook-lab ou envoyé sur demande. Il pointe déjà vers https://niki977.github.io/ultraspeaker-flipbook-lab/ : inutile de le modifier.

Configuration requise : PowerPoint de Microsoft 365 pour Mac, Windows ou le web.

PowerPoint pour Mac

  1. Quittez PowerPoint (⌘Q).
  2. Dans le Finder, appuyez sur ⌘ + Maj + G et collez : ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. S'il n'existe pas, créez un dossier nommé wef et copiez-y le manifeste. Si une version précédente s'y trouve, remplacez-la.
  4. Ouvrez PowerPoint et une présentation : dans Accueil, vous trouvez le groupe The Ultraspeaker avec le bouton Flipbook Lab.

Si l'ancienne version apparaît encore : quittez PowerPoint, videz ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches et rouvrez-le.

PowerPoint pour Windows

  1. Créez un dossier, par exemple C:\FlipbookLab, et copiez-y le manifeste.
  2. Clic droit sur le dossier → Propriétés → Partage → Partager…, choisissez votre utilisateur, Partager puis Terminé. Notez le chemin réseau (du type \\NOM-PC\FlipbookLab).
  3. Dans PowerPoint : Fichier → Options → Centre de gestion de la confidentialité → Paramètres du Centre de gestion de la confidentialité… → Catalogues de compléments approuvés. Collez le chemin réseau dans URL du catalogue, Ajouter un catalogue, cochez Afficher dans le menu, puis OK.
  4. Fermez et rouvrez PowerPoint, allez dans Accueil → Compléments → DOSSIER PARTAGÉ, sélectionnez The Ultraspeaker Flipbook Lab et Ajouter.

PowerPoint pour le web

Accueil → Compléments → Plus de compléments → Mes compléments → Charger mon complément et sélectionnez le manifeste.

3 · Essai

  1. Cliquez sur Accueil → Flipbook Lab : le volet s'ouvre.
  2. Cliquez sur Ouvrir Flipbook Lab : l'app s'ouvre dans le navigateur.
  3. Ouvrez le guide d'exemple, créez une vidéo en MP4 avec couleur et insérez-la avec Insertion → Vidéo → Vidéo à partir d'un fichier.

The Ultraspeaker Flipbook Lab installieren

Zuletzt aktualisiert: 12. November 2026

Verantwortlich: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

Die Webversion wird nicht installiert: Öffnen Sie niki977.github.io/ultraspeaker-flipbook-lab in einem aktuellen Chrome, Edge oder Safari, auf Computer, Tablet oder Telefon.

1 · Auf dem Home-Bildschirm

  • iPhone und iPad (Safari): Tippen Sie auf Teilen → Zum Home-Bildschirm. Das Symbol „Flipbook Lab“ erscheint.
  • Android (Chrome): Menü ⋮ → Zum Startbildschirm hinzufügen (oder App installieren).
  • Computer: In Chrome und Edge können Sie sie über das Symbol in der Adressleiste installieren oder als Lesezeichen speichern.

2 · PowerPoint-Bereich

Der Bereich für PowerPoint wird gerade getestet und ist bald verfügbar. Nutzen Sie bis dahin die Webversion.

Der Bereich fügt die Schaltfläche Flipbook Lab auf der Registerkarte Start in der Gruppe The Ultraspeaker hinzu und öffnet die App im Browser. Sie brauchen das Manifest ultraspeaker-flipbook-lab-manifest.xml aus dem Repository github.com/niki977/ultraspeaker-flipbook-lab oder auf Anfrage von uns. Es verweist bereits auf https://niki977.github.io/ultraspeaker-flipbook-lab/: Sie müssen es nicht ändern.

Voraussetzungen: PowerPoint aus Microsoft 365 für Mac, Windows oder das Web.

PowerPoint für Mac

  1. Beenden Sie PowerPoint (⌘Q).
  2. Drücken Sie im Finder ⌘ + Umschalt + G und fügen Sie ein: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/
  3. Falls nicht vorhanden, legen Sie einen Ordner wef an und kopieren Sie das Manifest hinein. Liegt dort schon eine ältere Version, ersetzen Sie sie.
  4. Öffnen Sie PowerPoint und eine Präsentation: Unter Start finden Sie die Gruppe The Ultraspeaker mit der Schaltfläche Flipbook Lab.

Erscheint noch die alte Version: Beenden Sie PowerPoint, leeren Sie ~/Library/Containers/com.microsoft.Powerpoint/Data/Library/Caches und öffnen Sie es erneut.

PowerPoint für Windows

  1. Legen Sie einen Ordner an, zum Beispiel C:\FlipbookLab, und kopieren Sie das Manifest hinein.
  2. Rechtsklick auf den Ordner → Eigenschaften → Freigabe → Freigeben…, Ihren Benutzer wählen, Freigeben und Fertig. Notieren Sie den Netzwerkpfad (ähnlich \\PC-NAME\FlipbookLab).
  3. In PowerPoint: Datei → Optionen → Trust Center → Einstellungen für das Trust Center… → Kataloge vertrauenswürdiger Add-Ins. Fügen Sie den Netzwerkpfad bei Katalog-URL ein, Katalog hinzufügen, aktivieren Sie Im Menü anzeigen, dann OK.
  4. Schließen und öffnen Sie PowerPoint erneut, gehen Sie zu Start → Add-Ins → FREIGEGEBENER ORDNER, wählen Sie The Ultraspeaker Flipbook Lab und Hinzufügen.

PowerPoint für das Web

Start → Add-Ins → Weitere Add-Ins → Meine Add-Ins → Mein Add-In hochladen und das Manifest auswählen.

3 · Ausprobieren

  1. Klicken Sie auf Start → Flipbook Lab: Der Bereich öffnet sich.
  2. Klicken Sie auf Flipbook Lab öffnen: Die App öffnet sich im Browser.
  3. Öffnen Sie die Beispiel-Anleitung, erstellen Sie ein Video als MP4 mit Farbe und fügen Sie es mit Einfügen → Video → Video aus Datei ein.
