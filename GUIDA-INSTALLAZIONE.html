Installare The Ultraspeaker Check Lab

Ultimo aggiornamento: 12 novembre 2026

Titolare: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

La versione web non si installa: apri niki977.github.io/ultraspeaker-check-lab in Chrome, Edge o Safari aggiornati. Serve per PowerPoint (.pptx) e per Keynote (.key).

1 · Sulla schermata Home

  • iPhone e iPad (Safari): tocca Condividi → Aggiungi alla schermata Home. Compare l’icona «Check Lab».
  • Android (Chrome): menu ⋮ → Aggiungi a schermata Home (o Installa app).
  • Computer: in Chrome ed Edge puoi installarla dall’icona nella barra degli indirizzi, oppure salvarla tra i preferiti.

2 · Pannello di PowerPoint

Il pannello per PowerPoint è in fase di prova e sarà disponibile a breve.

Il file del manifest si scarica da qui: ultraspeaker-check-lab-manifest.xml.

Windows

  1. Crea una cartella (per esempio C:\AddinManifest), copiaci ultraspeaker-check-lab-manifest.xml e condividila (tasto destro › Proprietà › Condivisione). Annota il percorso di rete, per esempio \\NOMEPC\AddinManifest.
  2. PowerPoint › File › Opzioni › Centro protezione › Impostazioni Centro protezione › Cataloghi componenti aggiuntivi attendibili: incolla il percorso, Aggiungi catalogo, spunta Mostra nel menu, OK.
  3. Riavvia PowerPoint › Home › Componenti aggiuntivi › Altri componenti aggiuntivi › CARTELLA CONDIVISA › The Ultraspeaker Check Lab › Aggiungi.

Mac

  1. Finder › Vai › Vai alla cartella: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/. Crea la cartella wef se non c’è e copiaci ultraspeaker-check-lab-manifest.xml.
  2. Riavvia PowerPoint › Home › Componenti aggiuntivi › The Ultraspeaker Check Lab.

PowerPoint per il web

  1. Home › Componenti aggiuntivi › Altri componenti aggiuntivi › I miei componenti aggiuntivi › Carica componente aggiuntivo e scegli ultraspeaker-check-lab-manifest.xml.

Dopo il caricamento trovi il pulsante Check Lab nella scheda Home, gruppo The Ultraspeaker. Se avevi una versione precedente, chiudi PowerPoint con ⌘Q (Mac) o dalla barra delle applicazioni (Windows) e riaprilo.

3 · Requisiti

PowerPoint per Microsoft 365, 2021 o successivo su Windows e Mac, oppure PowerPoint per il web. «Applica» richiede PowerPoint con le funzioni del pannello 1.4, la banda dietro il testo la versione 1.8: se mancano, i pulsanti non compaiono.

Installing The Ultraspeaker Check Lab

Last updated: 12 November 2026

Owner: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

The web version needs no installation: open niki977.github.io/ultraspeaker-check-lab in an up-to-date Chrome, Edge or Safari. It works for PowerPoint (.pptx) and Keynote (.key).

1 · On the Home screen

  • iPhone and iPad (Safari): tap Share → Add to Home Screen. The “Check Lab” icon appears.
  • Android (Chrome): menu ⋮ → Add to Home screen (or Install app).
  • Computer: in Chrome and Edge you can install it from the icon in the address bar, or bookmark it.

2 · PowerPoint pane

The PowerPoint pane is being tested and will be available soon.

Download the manifest file here: ultraspeaker-check-lab-manifest.xml.

Windows

  1. Create a folder (for example C:\AddinManifest), copy ultraspeaker-check-lab-manifest.xml into it and share it (right-click › Properties › Sharing). Note the network path, for example \\PCNAME\AddinManifest.
  2. PowerPoint › File › Options › Trust Center › Trust Center Settings › Trusted Add-in Catalogs: paste the path, Add catalog, tick Show in Menu, OK.
  3. Restart PowerPoint › Home › Add-ins › More Add-ins › SHARED FOLDER › The Ultraspeaker Check Lab › Add.

Mac

  1. Finder › Go › Go to Folder: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/. Create the wef folder if it is missing and copy ultraspeaker-check-lab-manifest.xml into it.
  2. Restart PowerPoint › Home › Add-ins › The Ultraspeaker Check Lab.

PowerPoint for the web

  1. Home › Add-ins › More Add-ins › My Add-ins › Upload My Add-in and choose ultraspeaker-check-lab-manifest.xml.

Once loaded, you find the Check Lab button on the Home tab, in the The Ultraspeaker group. If you had an earlier version, quit PowerPoint (⌘Q on Mac) and open it again.

3 · Requirements

PowerPoint for Microsoft 365, 2021 or later on Windows and Mac, or PowerPoint for the web. “Apply” needs PowerPoint with pane features 1.4, the band behind the text version 1.8: if they are missing, the buttons do not appear.

The Ultraspeaker Check Lab installieren

Zuletzt aktualisiert: 12. November 2026

Verantwortlicher: Nicholas D. Charles (The Ultraspeaker) · info@theultraspeaker.com

Die Webversion muss nicht installiert werden: Öffnen Sie niki977.github.io/ultraspeaker-check-lab in einem aktuellen Chrome, Edge oder Safari. Sie funktioniert für PowerPoint (.pptx) und Keynote (.key).

1 · Auf dem Home-Bildschirm

  • iPhone und iPad (Safari): Tippen Sie auf Teilen → Zum Home-Bildschirm. Das Symbol „Check Lab“ erscheint.
  • Android (Chrome): Menü ⋮ → Zum Startbildschirm hinzufügen (oder App installieren).
  • Computer: In Chrome und Edge können Sie sie über das Symbol in der Adressleiste installieren oder als Lesezeichen speichern.

2 · PowerPoint-Aufgabenbereich

Der PowerPoint-Aufgabenbereich wird gerade getestet und ist bald verfügbar.

Die Manifestdatei laden Sie hier herunter: ultraspeaker-check-lab-manifest.xml.

Windows

  1. Erstellen Sie einen Ordner (zum Beispiel C:\AddinManifest), kopieren Sie ultraspeaker-check-lab-manifest.xml hinein und geben Sie ihn frei (Rechtsklick › Eigenschaften › Freigabe). Notieren Sie den Netzwerkpfad, zum Beispiel \\PCNAME\AddinManifest.
  2. PowerPoint › Datei › Optionen › Trust Center › Einstellungen für das Trust Center › Kataloge vertrauenswürdiger Add-Ins: Pfad einfügen, Katalog hinzufügen, Im Menü anzeigen aktivieren, OK.
  3. PowerPoint neu starten › Start › Add-Ins › Weitere Add-Ins › FREIGEGEBENER ORDNER › The Ultraspeaker Check Lab › Hinzufügen.

Mac

  1. Finder › Gehe zu › Gehe zum Ordner: ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/. Legen Sie den Ordner wef an, falls er fehlt, und kopieren Sie ultraspeaker-check-lab-manifest.xml hinein.
  2. PowerPoint neu starten › Start › Add-Ins › The Ultraspeaker Check Lab.

PowerPoint für das Web

  1. Start › Add-Ins › Weitere Add-Ins › Meine Add-Ins › Mein Add-In hochladen und ultraspeaker-check-lab-manifest.xml wählen.

Danach finden Sie die Schaltfläche Check Lab auf der Registerkarte Start, Gruppe The Ultraspeaker. Hatten Sie eine frühere Version, beenden Sie PowerPoint (⌘Q auf dem Mac) und öffnen Sie es erneut.

3 · Voraussetzungen

PowerPoint für Microsoft 365, 2021 oder neuer unter Windows und Mac, oder PowerPoint für das Web. „Anwenden“ benötigt PowerPoint mit den Aufgabenbereich-Funktionen 1.4, das Band hinter dem Text die Version 1.8: Fehlen sie, erscheinen die Schaltflächen nicht.
